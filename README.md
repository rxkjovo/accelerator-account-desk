# 加速账户助手

Windows 本地桌面工具，用于记录本人 QQ / 微博账号、关联手机号、加速器时长、兑换结果及注销进度。

## 打开软件

构建完成后，双击 `dist/加速账户助手-0.3.1/加速账户助手.exe`，或使用桌面的「加速账户助手」快捷方式。

请保留整个文件夹，exe 需要同目录的程序文件和 SQLite 组件。发布文件夹已包含 .NET 运行时，使用者无需另装开发 SDK。

## 注册 QQ

1. 在「手机号」中预先保存本人号码，也可在注册窗口中添加。当前自动填写支持 +86 中国大陆手机号。
2. 点击首页「注册 QQ」，从下拉框中选择号码，再点击「开始注册 / 获取验证码」。软件生成独立昵称和 10 位随机密码，在软件内的 QQ 官方页面填写资料并请求验证码。已有草稿及已注册账号的密码保持原值。
3. 填写收到的 6 位验证码，阅读窗口中的 QQ 服务协议、隐私政策，再点击「同意协议并注册」。软件协助提交并读取结果。QQ 若要求滑块、扫码或其他安全验证，需本人在右侧官方页面完成。
4. 读到明确的成功提示与 QQ 号后，软件自动保存 QQ 号、关联手机号和加密密码；会员到期仍保持未知。0.3.1 已适配本人实际成功页中「注册成功 → 纯数字 QQ 号 → 三天内未登录回收提示」的布局，并保留歧义与来源检查；读不到结果时，展开「结果未读取？手动确认」粘贴 QQ 号、确认官方注册成功，并明确勾选默认未选中的「本次使用软件生成的密码」，或输入在官方页面实际设置的密码。仅确认注册成功不能推断使用了哪个密码；密码来源不明确或保存失败时会保留原加密草稿。

软件不自动重复发送验证码或循环注册。已生成资料会先存入本机加密草稿；网络中断或关闭窗口后可重新打开找回。待确认草稿完成前不能更换手机号，避免记录错配。确认没有已注册但未保存的账号后，才使用「放弃当前草稿并重新选择」。

注册窗口直接提供「本次账号密码」及显示、复制按钮，默认遮盖。保存后也可在账号列表选中账号，点击「查看 / 保存密码」。手动添加账号不会自动猜测或绑定注册草稿密码；应先通过注册向导保存结果，避免只留下没有密码的手动账号记录。

## 账号与时长

1. 在「手机号」中添加本人号码和备注；官方限制日期未知时留空。
2. 在「账号总览」添加 QQ / 微博账号，选择关联手机号。
3. 右侧流程面板可打开 QQ 注册向导或本机迅雷客户端。首次在「设置与说明」选择迅雷游戏加速器的 exe。
4. QQ 注册按上述向导操作；迅雷授权、兑换与注销仍在官方界面由本人完成。打开入口不会自动标记成功。
5. 完成官方兑换后，点击「记录兑换结果」，填写口令、成功/失败/待确认、实际到账时长和实际到期时间。
6. 到期情况显示在首页统计和账号列表中。运行期间每分钟刷新；关闭软件时不提供后台通知。
7. 账号「编辑 → 注销记录」中填写官方注销进度与日期。历史账号继续保留查询。

未记录的日期显示未知，不会自动加上 10～15 天。会员到期、第三方账号注销、手机号再次注册限制和迅雷领取资格分别处理。微博入口来自用户提供的客户端截图，其完整注册与兑换资格尚未验证。

同一条成功兑换记录的后续编辑只修改历史记录，不会再次改变账号的时长。如需纠正已填错的到期时间，请在账号编辑页修改「会员时长」。

## 数据与备份

默认目录：`%LOCALAPPDATA%\AcceleratorAccountDesk`。

- `accounts.db`：SQLite 数据库，包含账号、手机号、兑换记录及密码密文。
- `settings.json`：本机客户端路径。
- `qq-registration-draft.bin`：若存在，保存本次未确认注册的加密资料。
- `qq-browser`：内嵌 QQ 官方页面的浏览器数据，不属于账号列表或密码导出。

关闭软件后，复制整个数据目录即可备份。密码使用 Windows DPAPI 加密并绑定当前 Windows 用户及账号；更换 Windows 用户、重装系统或在其他电脑恢复备份后可能无法解密，不能把普通文件复制当作密码的跨设备恢复方案。软件不保存短信验证码或授权令牌。

选中账号后点击「查看 / 保存密码」，默认隐藏，勾选后显示，也可补充或更新实际密码。复制密码后，软件会在 30 秒后尝试清除仍未被替换的剪贴板内容；若其他程序占用剪贴板或软件异常退出，自动清除可能无法完成。手机号在列表中脱敏，可在编辑窗口查看或通过「复制选中号码」复制。

也可以通过命令行选择独立数据目录：

```powershell
.\加速账户助手.exe --data-dir "D:\我的账号记录"
```

CSV 导出保留界面显示的手机号脱敏值；它用于查看，完整备份请复制数据目录。

## 从源代码构建

需要 .NET SDK `10.0.404`（或同补丁系列兼容版本）与 PowerShell 7；当前工作目录 `.tools/dotnet` 中已准备本地 SDK。内嵌注册页使用 Microsoft Edge WebView2 Runtime；当前电脑已安装。未安装时需从微软官方来源安装，或通过系统浏览器完成后手动确认结果。

```powershell
.\scripts\test.ps1
.\scripts\build.ps1
```

测试包含实际 SQLite 持久化、版本升级、未知日期、到期边界、事务回滚、并发写入、Windows 密码加密与草稿恢复，以及真实 WebView2 模拟页面的填写/验证码/提交桥接和 WPF 表单保存。

浏览器测试拦截所有请求并返回明确标记的本地模拟页面，不会向 QQ 发送短信或注册。已只读核对本人实际操作后的官方成功页；修正版的识别、账号与密码保存使用隔离数据库和本地页面验证，未另行执行真实短信、注册或安全验证。
