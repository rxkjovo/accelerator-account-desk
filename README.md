# 加速账户助手

Windows 本地桌面工具，用于记录本人 QQ / 微博账号、关联手机号、加速器时长、兑换结果及注销进度。

## 打开软件

构建完成后，双击 `dist/加速账户助手-0.2.0/加速账户助手.exe`。

请保留整个文件夹，exe 需要同目录的程序文件和 SQLite 组件。发布文件夹已包含 .NET 运行时，使用者无需另装开发 SDK。

## 使用流程

1. 在「手机号」中添加本人号码和备注；官方限制日期未知时留空。
2. 在「账号总览」添加 QQ / 微博账号，选择关联手机号。
3. 右侧流程面板可打开 QQ 官方注册入口或本机迅雷客户端。首次在「设置与说明」选择迅雷游戏加速器的 exe。
4. 注册、短信验证、授权、兑换与注销确认均在官方界面由本人完成；打开入口不会自动标记成功。
5. 完成官方兑换后，点击「记录兑换结果」，填写口令、成功/失败/待确认、实际到账时长和实际到期时间。
6. 到期情况显示在首页统计和账号列表中。运行期间每分钟刷新；关闭软件时不提供后台通知。
7. 账号「编辑 → 注销记录」中填写官方注销进度与日期。历史账号继续保留查询。

未记录的日期显示未知，不会自动加上 10～15 天。会员到期、第三方账号注销、手机号再次注册限制和迅雷领取资格分别处理。微博入口来自用户提供的客户端截图，其完整注册与兑换资格尚未验证。

同一条成功兑换记录的后续编辑只修改历史记录，不会再次改变账号的时长。如需纠正已填错的到期时间，请在账号编辑页修改「会员时长」。

## 数据与备份

默认目录：`%LOCALAPPDATA%\AcceleratorAccountDesk`。

- `accounts.db`：SQLite 数据库，包含账号、手机号及兑换记录。
- `settings.json`：本机客户端路径。

关闭软件后，复制整个数据目录即可备份。软件不记录密码、短信验证码或授权令牌。手机号在列表中脱敏，可在编辑窗口查看或通过「复制选中号码」复制。

也可以通过命令行选择独立数据目录：

```powershell
.\加速账户助手.exe --data-dir "D:\我的账号记录"
```

CSV 导出保留界面显示的手机号脱敏值；它用于查看，完整备份请复制数据目录。

## 从源代码构建

需要 .NET SDK `10.0.404`（或同补丁系列兼容版本）；当前工作目录 `.tools/dotnet` 中已准备本地 SDK。

```powershell
.\scripts\test.ps1
.\scripts\build.ps1
```

测试包含实际 SQLite 持久化、未知日期、到期边界、失败兑换、事务回滚、重复编辑、并发写入，以及日期输入、CSV 导出和设置保存。

本地测试使用独立临时目录，不会注册外部账号、发送短信、提交兑换或申请注销。
