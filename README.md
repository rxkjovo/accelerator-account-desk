# 加速账户助手

Windows 本地桌面工具，用于记录本人 QQ / 微博账号、关联手机号、加速器时长、兑换结果及注销进度。

[下载最新版](https://github.com/rxkjovo/accelerator-account-desk/releases/latest) · [反馈问题](https://github.com/rxkjovo/accelerator-account-desk/issues) · [参与修改](CONTRIBUTING.md)

推荐下载 Release 中的 `AcceleratorAccountDesk-版本-Setup-win-x64.exe`，双击进入中文安装向导，点击“浏览”自定义安装目录。安装后提供桌面和开始菜单快捷方式，可在 Windows 设置中卸载。账号数据独立保存，卸载程序保留个人记录。

也可以下载 `AcceleratorAccountDesk-版本-win-x64.zip` 使用免安装版：全部解压后双击「加速账户助手.exe」。软件适用于 Windows 10/11 x64，已包含 .NET 运行时；QQ 内嵌页面另需 Microsoft Edge WebView2 Runtime。朋友首次运行会建立自己的本机记录，不包含发布者的账号和密码。

## 在线更新与分享

点击左下角「检查更新」，或「设置与说明 → 软件更新」。程序从本仓库的最新正式 GitHub Release 读取版本、清单和安装包；下载完成核对大小及 SHA-256 后，由独立更新程序等待当前程序正常退出，安装到同级新版本文件夹，并使用原数据目录启动新版。原程序文件夹保留；安装或新版启动失败时尝试恢复旧版。桌面快捷方式只有在指向当前程序时才更新。

检查和下载需要能访问 GitHub。连接失败、取消或校验不通过时可继续使用当前版本。更新包只有完整性校验，未做 Windows 发布者代码签名。可以手动下载新包并解压到独立目录。

把 Release 安装 EXE、免安装 ZIP 或下载页分享给朋友即可；不要打包自己的 `%LOCALAPPDATA%\AcceleratorAccountDesk`。源码采用 MIT 许可，欢迎 Fork 和提交 PR。

## 打开软件

构建完成后，双击 `dist/加速账户助手-0.3.5/加速账户助手.exe`，或使用桌面的「加速账户助手」快捷方式。

请保留整个文件夹，exe 需要同目录的程序文件和 SQLite 组件。发布文件夹已包含 .NET 运行时，使用者无需另装开发 SDK。

## 注册 QQ

1. 在「手机号」中预先保存本人号码，也可在注册窗口中添加。当前自动填写支持 +86 中国大陆手机号。
2. 点击首页「注册 QQ」，从下拉框中选择号码，再点击「开始注册 / 获取验证码」。软件生成独立昵称和 10 位随机密码，在软件内的 QQ 官方页面填写资料并点击发送按钮。仅点击按钮不能确认短信已发送，需核对官方提示和本人短信。已有草稿及已注册账号的密码保持原值。
3. 填写收到的 6 位验证码，阅读窗口中的 QQ 服务协议、隐私政策，再点击「同意协议并注册」。软件协助提交并读取结果。QQ 若要求滑块、扫码或其他安全验证，需本人在右侧官方页面完成。
4. 读到明确的成功提示与 QQ 号后，软件自动保存 QQ 号、关联手机号和加密密码；会员到期仍保持未知。0.3.1 已适配本人实际成功页中「注册成功 → 纯数字 QQ 号 → 三天内未登录回收提示」的布局，并保留歧义与来源检查；读不到结果时，展开「结果未读取？手动确认」粘贴 QQ 号、确认官方注册成功，并明确勾选默认未选中的「本次使用软件生成的密码」，或输入在官方页面实际设置的密码。仅确认注册成功不能推断使用了哪个密码；密码来源不明确或保存失败时会保留原加密草稿。

软件不自动重复发送验证码或循环注册。已生成资料会先存入本机加密草稿；网络中断或关闭窗口后可重新打开找回。待确认草稿完成前不能更换手机号，避免记录错配。确认没有已注册但未保存的账号后，才使用「放弃当前草稿并重新选择」。

0.3.5 会识别官方可见的「由于安全限制，需要您下载手机QQ注册账号」提示，包括点击后稍晚出现的情况。遇到这条提示会停止网页注册及结果监测、停用发送和提交按钮，将限制状态连同原草稿加密保留，重开向导仍可查看。该提示来自 QQ 官方，软件不能解除，也不代表此手机号永久不能网页注册。若本人按官方方式完成注册，可展开手动确认保存实际 QQ 号及实际密码，不能默认沿用电脑草稿生成的密码。

注册窗口直接提供「本次账号密码」及显示、复制按钮，默认遮盖。保存后也可在账号列表选中账号，点击「查看 / 保存密码」。手动添加账号不会自动猜测或绑定注册草稿密码；应先通过注册向导保存结果，避免只留下没有密码的手动账号记录。

## 账号与时长

侧栏「兑换码」可直接查看并复制之前截图中的 7 个口令：`JSQPHB`、`XL888`、`XL7878`、`XL1314`、`XL6789`、`XL8989`、`ws1997`。它们来自用户提供的第三方截图，均未验证有效性或到账时长。窗口也支持保存其他兑换码，保留原始大小写；复制不会自动兑换、增加时长或标记成功。请在迅雷客户端核对实际结果后，再记录兑换情况。

个人兑换码文件无法读取时，内置 7 个码仍显示并可以复制；原个人文件保留，修复前不覆盖保存。

1. 在「手机号」中添加本人号码和备注；官方限制日期未知时留空。
2. 在「账号总览」添加 QQ / 微博账号，选择关联手机号。
3. 右侧流程面板可打开 QQ 注册向导或本机迅雷客户端。首次在「设置与说明」选择迅雷游戏加速器的 exe。
4. QQ 注册按上述向导操作；迅雷授权、兑换与注销仍在官方界面由本人完成。打开入口不会自动标记成功。
5. 完成官方兑换后，点击「记录兑换结果」，填写口令、成功/失败/待确认、实际到账时长和实际到期时间。
6. 到期情况显示在首页统计和账号列表中。运行期间每分钟刷新；关闭软件时不提供后台通知。
7. 账号「编辑 → 注销记录」中填写官方注销进度与日期。历史账号继续保留查询。

未记录的日期显示未知，不会自动加上 10～15 天。会员到期、第三方账号注销、手机号再次注册限制和迅雷领取资格分别处理。微博入口来自用户提供的客户端截图，其完整注册与兑换资格尚未验证。

同一条成功兑换记录的后续编辑只修改历史记录，不会再次改变账号的时长。如需纠正已填错的到期时间，请在账号编辑页修改「会员时长」。

## 数据与备份

默认目录：`%LOCALAPPDATA%\AcceleratorAccountDesk`。

- `accounts.db`：SQLite 数据库，包含账号、手机号、兑换记录及密码密文。
- `settings.json`：本机客户端路径。
- `qq-registration-draft.bin`：若存在，保存本次未确认注册的加密资料。
- `redemption-codes.json`：若存在，保存本人另行添加的兑换码；截图中的 7 个口令随程序提供。
- `qq-browser`：内嵌 QQ 官方页面的浏览器数据，不属于账号列表或密码导出。

关闭软件后，复制整个数据目录即可备份。密码使用 Windows DPAPI 加密并绑定当前 Windows 用户及账号；更换 Windows 用户、重装系统或在其他电脑恢复备份后可能无法解密，不能把普通文件复制当作密码的跨设备恢复方案。软件不保存短信验证码或授权令牌。

选中账号后点击「查看 / 保存密码」，默认隐藏，勾选后显示，也可补充或更新实际密码。复制密码后，软件会在 30 秒后尝试清除仍未被替换的剪贴板内容；若其他程序占用剪贴板或软件异常退出，自动清除可能无法完成。手机号在列表中脱敏，可在编辑窗口查看或通过「复制选中号码」复制。

也可以通过命令行选择独立数据目录：

```powershell
.\加速账户助手.exe --data-dir "D:\我的账号记录"
```

CSV 导出保留界面显示的手机号脱敏值；它用于查看，完整备份请复制数据目录。

## 从源代码构建

需要 .NET SDK `10.0.404`（或同补丁系列兼容版本）与 PowerShell 7；当前工作目录 `.tools/dotnet` 中已准备本地 SDK。内嵌注册页使用 Microsoft Edge WebView2 Runtime；当前电脑已安装。未安装时需从微软官方来源安装，或通过系统浏览器完成后手动确认结果。

```powershell
.\scripts\test.ps1
.\scripts\build.ps1
.\scripts\package.ps1 -SkipBuild
.\scripts\build-installer.ps1 -SkipBuild
```

测试包含实际 SQLite 持久化、版本升级、未知日期、到期边界、事务回滚、并发写入、Windows 密码加密与草稿恢复，以及真实 WebView2 模拟页面的填写/验证码/提交桥接和 WPF 表单保存。

构建安装 EXE 另需 [Inno Setup](https://jrsoftware.org/isdl.php)，脚本可自动发现常见安装位置，或传入 `-CompilerPath "路径\ISCC.exe"`。中文翻译来自 Inno Setup 官方源码的用户贡献语言文件，保留原文件头。

浏览器测试拦截所有请求并返回明确标记的本地模拟页面，不会向 QQ 发送短信或注册。已只读核对本人实际操作后的官方成功页；修正版的识别、账号与密码保存使用隔离数据库和本地页面验证，未另行执行真实短信、注册或安全验证。限制回归覆盖即时及延迟出现的提示、隐藏模板不误判、发送/提交停用、重开草稿恢复和手动实际密码保存。
