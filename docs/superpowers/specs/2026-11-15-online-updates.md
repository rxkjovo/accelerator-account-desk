# 分享包与 GitHub Releases 在线升级

用户要求可分享给朋友，并选择 GitHub Releases 作为在线更新渠道，随后明确同意创建公开仓库供朋友一起修改。已核实账号 rxkjovo，并创建公开仓库 rxkjovo/accelerator-account-desk；源码按 MIT 许可开放。

本次交付 0.3.3：独立分享 ZIP、使用说明、更新清单，以及软件中的检查、下载进度、取消和安装后重启。GitHub 仓库配置只包含公开仓库名，不携带任何访问令牌。GitHub 最新正式 Release 必须有固定产品、Windows x64、匹配版本和文件名的清单及 ZIP；下载核对长度与 SHA-256，拒绝降级、缺失文件、陌生下载地址和不安全重定向。

独立更新进程在用户点击下载并更新后启动；等待当前进程正常退出，不强杀进程。将经校验的 ZIP 安装到当前程序目录的同级版本目录，保留当前版本和独立的数据目录。解包拒绝绝对路径、目录穿越、重复路径、链接、异常体积和用户数据文件；安装完成后更新属于本软件的桌面快捷方式并启动新版。失败时保留旧版，记录结果并尝试恢复旧版启动。自定义数据目录通过参数传给新进程。

分享包只包含发布程序、运行时和公开说明，不含 accounts.db、设置、注册草稿、浏览器数据或任何账号密码。密码仍绑定朋友自己的 Windows 用户。未配置或未发布 GitHub 更新源时明确显示尚未可用，不把本地模拟测试称作真实在线升级成功。

验证覆盖正式版本比较、GitHub 元数据与清单、可信下载地址、大小/哈希不符、取消、路径穿越和用户文件保护、安装失败保留旧版、实际独立更新进程与隔离数据启动。发布前生成可以审阅的完整包和 Release 文案；实际公开发布需有明确的目标仓库。
