# 游戏客户端视觉修订

用户在试用后否定前两版界面，并明确选择“参考所提供的迅雷截图：深色游戏客户端”。本次视觉修订已授权直接执行。

## 视觉依据

- 使用用户提供的迅雷截图作为视觉参考，游戏区域裁切为本地氛围图，不包含顶部头像及个人界面。
- 暖黑和橄榄灰作为背景，荧绿用于主要动作，状态警示使用语义色。
- 使用真实统一的图标与独立应用图标，账号和时长仍以实际数据展示。
- 首页组织为游戏主视觉、三步操作流程、紧凑统计及账号列表；详情承担账号状态查询，避免重复流程。
- QQ / 微博、手机号、兑换记录、未知日期与注销状态保持一致的记录语义。
- 中文基础字号 14，主要正文接近白色、次级标签保持可读对比度；荧绿按钮使用深色文字。输入文字与背景的已测对比度为 13.81:1，主要按钮为 12.34:1。
- 编辑窗口按相关字段分列，较长内容允许滚动；1100×680 的紧凑窗口可显示三条完整示例账号。较窄列表保留水平滚动和完整内容提示。

## 检查方法

使用独立测试程序对本项目的 WPF 视觉树进行离屏渲染，检查空列表、有示例记录、紧凑窗口和账号编辑器。预览图中的账号、手机号和时长均为明确标记的示例，不写入用户数据目录。

已检查六张离屏图：空首页、示例首页、紧凑首页、账号编辑、手机号编辑、兑换记录编辑。表单检查使用实际 WPF 对象、仓库回调和独立数据库；9 项保存与错误处理检查通过。

离屏预览不等于操作系统截图，也不代替真实窗口启动检查。真实注册、短信验证、授权、兑换和注销未在本次验证中执行。
