## 功能与数据边界

- 一次处理用户选择的一个号码；不批量调度、轮换号码或绕过 QQ 安全验证。
- 软件生成昵称与随机密码，点击开始后辅助填入固定官方页面并请求验证码。验证码和最终提交由用户按钮明确触发，提交按钮标注「同意协议并注册」并提供协议、隐私链接。
- 官方明确显示成功和 QQ 号后才自动保存；失败、未知或含糊结果保留待确认草稿。手动补录要求明确确认官方结果，并确认本次使用生成密码或主动填写实际密码。没有自动增加会员时长。
- 数据库版本 1 升级到版本 2；密码密文与账号原子保存，常规编辑不擦除密码。待确认资料另存 DPAPI 加密草稿，账号保存成功后才清除。
- 恢复草稿后的号码必须与原草稿一致；提交与保存均重新校验，数据库事务内再次核对。号码变化时保留草稿并拒绝错配保存。无法解密已有密码时，编辑器可打开供本人明确替换；打开、取消及空密码保存不会擦除密文。
- 密码绑定当前 Windows 用户，跨用户或重装后的解密未验证。测试证明数据库和草稿文件不包含测试密码明文；不声称 .NET 不可变字符串或 Windows 内部内存已完全清零。
