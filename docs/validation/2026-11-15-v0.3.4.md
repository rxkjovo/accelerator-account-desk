# 0.3.4 GitHub 匿名接口限流修复

0.3.3 的源码和正式 Release 已上传。真实匿名网络验证发现 GitHub API 返回 403 rate limit exceeded，而同仓库的 `/releases/latest/download/update-manifest.json` 可正常访问并重定向至 GitHub 官方资产 CDN。

0.3.4 对 API 403/429、服务器错误及连接失败增加官方 Release 清单备用检查；仍只使用配置的仓库，检查产品、系统、正式版本、文件名、大小、SHA-256 及安装包内程序版本。GitHub 域名重定向必须留在同仓库的 releases 路径，CDN 只允许既有 GitHub 资产主机。已有正式版本不覆盖重发，因此使用新版本号。

更新逻辑 20 项通过，其中新增限流备用成功、版本相同不更新、产品不符和跨仓库重定向拒绝。完整测试累计 136 项通过；新版本表单测试从当前程序集动态生成未来版本，后续提升版本时仍验证真实的新版提示。

在线下载和实际安装的最终证据在发布后补充。本地报告和下载包保持在忽略目录中，不上传用户数据。
