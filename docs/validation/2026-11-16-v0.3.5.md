# v0.3.5 QQ 注册限制状态修正

用户提供的官方页面显示「由于安全限制，需要您下载手机QQ注册账号」，但向导在点击发送按钮后立即显示「已请求验证码」，并允许继续提交。发送动作只证明点击成功，原逻辑也没有在发送后监测稍晚出现的页面提示。

修正后，点击发送显示等待官方响应；发送后只读监测最多两分钟，不重复发送。固定 QQ 官方来源的可见手机注册限制优先于通用待确认提示，停止监测及网页发送/提交操作，并在加密草稿中保留限制状态、原号码、昵称和密码。隐藏模板及普通下载/登录文字不触发限制。重开窗口保留原状态；手动结果保存继续要求本人确认实际 QQ 号及密码。该修正不解除 QQ 官方限制，也不推定手机号永久受限。
