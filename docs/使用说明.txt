加速账户助手 · 首次使用

1. 将 ZIP「全部解压」到一个固定位置，不要直接在压缩包内运行。
2. 双击「加速账户助手.exe」。保留同目录的所有文件。
3. 首次打开不会带入其他人的账号。在「手机号」添加本人号码，在「账号总览」添加账号或使用 QQ 注册向导。
4. 「设置与说明」中选择本机迅雷游戏加速器的 exe。迅雷授权、兑换及额外安全验证在官方界面完成。
5. 侧栏「兑换码」可复制口令，实际有效性和到账时长以官方结果为准。

更新软件

点击左下角「检查更新」，或「设置与说明 → 软件更新」。发现新版后点击「下载并更新」。
下载成功并校验后，软件会退出并重新打开新版；原版本文件夹保留。下载中断可重新操作。
连接 GitHub 失败时可继续使用当前版本，也可从项目 Releases 手动下载完整新包。
不要把新版解压进旧版覆盖混用，请使用单独的新文件夹。

本机数据与备份

默认目录：%LOCALAPPDATA%\AcceleratorAccountDesk
关闭软件后，复制整个数据目录即可备份记录。密码使用 Windows 用户加密，复制到别人的电脑或重装系统后可能无法解密。
分享时只发送下载的程序 ZIP；不要发送自己的数据目录。

运行环境

Windows 10/11 64 位。已包含 .NET 运行时。
QQ 官方内嵌页面需要 Microsoft Edge WebView2 Runtime。若缺少，请从微软官方安装：
https://developer.microsoft.com/microsoft-edge/webview2/
